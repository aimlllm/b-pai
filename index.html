考试概览

考试形式

  • 在 PSI 考试中心电脑上进行
  • 闭卷考试，不得携带任何资料
  • 单选题，每题 4 个选项；题数以考场说明为准
  • 考试时间 210 分钟（3.5 小时）
  • 及格要求以考场通知为准，不设本站统一分数线
  • 猜题不扣分，建议全部作答

两部分考试

  • 法律与商业考试 (Law & Business)：通常须通过，法定豁免另行审核
  • 行业专业考试 (Trade Exam)：B 牌 General Building 专业考试
  • 两项考试均需通过才能获得执照

考试费用与报名

  • 通过 CSLB 官网申请
  • 需要至少 4 年相关工作经验
  • 或相关学历 + 工作经验组合
  • 申请费用约 $450
  • 需提供指纹及背景调查

考试策略

  • 按当场题数分配每科 3.5 小时
  • 先做有把握的题目
  • 标记不确定的题目回头检查
  • 选择"最佳答案"而非"正确答案"
  • 注意题目中的关键词：最小、最大、至少等
  • 不确定时大胆猜测，不要留空

加州B牌承包商执照完全指南 / Complete Guide to California B Contractor License

什么是加州B牌承包商执照？ What is a California Class B Contractor License?

加州B牌承包商执照（California Class B General Building Contractor License）是由加州承包商执照委员会（CSLB, California Contractors State License Board）颁发的专业执照。B类执照持有者可以承接涉及至少两个不相关建筑工种的结构性建筑项目总包合同，包括住宅和商业建筑的新建、改建和翻修。这是加州最常见的承包商执照分类之一。根据加州法律（Business and Professions Code Section 7000 et seq.），任何金额达到$1,000或以上的建筑项目都必须由持照承包商执行。

两科均闭卷、四选一，每科3.5小时。官方公开考纲未承诺固定题数或统一及格百分比；以考场通知为准。B五领域与LAW七领域见上方官方考纲。

完整申请指南 → 近10年4年经验如何计算、由谁证明、学历抵扣、可并行步骤，以及18个月/90天/21天/48小时期限。

规范数字有建筑用途、材料、工种与例外条件，不宜背一张无条件数字表。加州沟槽防护与坠落防护应查具体Title 8条款。新题会明确计算前提并给来源。
