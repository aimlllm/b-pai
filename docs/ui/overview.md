# 界面合同

保留现有 indigo/slate 视觉与单页导航，使用 ui-ux-pro-max 的可见焦点、44px 操作区域与移动端溢出规则。设计稿：[练习页桌面与手机](practice-mockup.svg)，其中题目和计数为设计样本。

真实入口：`/#overview` 考试概览；`/licensing.html` 申请流程；`/#courses` 课程；`/#topics` 官方考纲；`/#practice` 练习；`/#resources` 资料；`/#guide` 公式与参考。

练习页状态：未答、已答正确、已答错误、筛选为空、错题为空。考试/领域/难度/题型是同页筛选，不产生新页面。申请指南用可展开区块减少手机阅读负担，关键期限始终可见。

- 筛选：改变下拉项或科目按钮 → 同页替换题池并清空本轮计分，状态文本报出可练题数；焦点保留在触发控件。
- 选择答案：显示正确答案、解析、来源和日期；按钮原生 disabled，重复点击不累计；答案反馈 aria-live。
- 前后题：只替换题卡，保留本轮答题状态；首/末题禁用相应按钮。
- 随机/重开：清空本轮；随机仅打乱当前筛选结果。
- 错题再练：从当前筛选范围选择已保存错题，开始新一轮；答对时从错题记录移除。无错题显示恢复按钮，不抛异常。
- 键盘：1–4 答题、方向键翻题；下拉、输入和链接焦点内不拦截原生按键；所有操作有可见焦点。
- 过渡：沿用150–200ms色彩反馈，关闭减少动态效果下的非必要动画与平滑滚动。避免筛选自动滚到页顶。

实际验证产物：[手机练习页](../qa/practice-mobile.jpg)、[桌面申请指南](../qa/licensing-desktop.jpg)、[手机申请指南](../qa/licensing-mobile.jpg)。截图是实现验证；上方SVG是独立设计稿。

无服务器异步加载/登录/上传流程。资料下载和申请链接打开官方外站，本站不代为提交。
